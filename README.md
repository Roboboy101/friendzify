# Friendzify - Social Media Platform

A lightweight and responsive social media platform for students to connect, share classroom details, and stay safe with SOS features.

## Tech Stack
- **Backend**: Node.js + Express (MVC pattern)
- **Frontend**: React.js
- **Database**: SQLite
- **Real-Time**: Socket.IO

## Project Structure
```
friendzify/
├── backend/          # Node.js + Express backend (MVC)
├── frontend/         # React.js frontend
└── database/         # SQLite database files
```

## Development Environment
- Windows with Cursor IDE
- Node.js and npm required

## Getting Started
1. Set up backend environment
2. Set up frontend environment
3. Install dependencies
4. Run development servers
